# path — числа книги, которые следуют из суждений и из пути баланса: вывод на ядре (MODEL §3.5)

```
python -B data/assumptions/evidence/path/derive_on_engine.py --start data/assumptions/evidence/path/out/derive_start.json
                                                                              # повтор вывода книги 0.1 → out/derive_out.json
python -B data/assumptions/evidence/path/derive_on_engine.py                  # вывод с чисел самой книги (ещё один круг шагов)
python -B data/assumptions/evidence/path/derive_on_engine.py --steps bridge,level --no-write   # отдельные шаги
python -B data/assumptions/evidence/path/marginal_loan.py                     # предельная экономика роста → out/marginal_loan_out.*
python -B data/assumptions/evidence/path/m13_cost_bases.py                    # базы расходов М13 → out/m13_cost_bases_out.*
python -B data/assumptions/evidence/path/acceptance.py                        # мерки маржи в условиях окон, сверка порядка
```

Весь путь одной командой — `python -B ops/tools/rederive.py [--dry-run]` из корня репозитория: она запускает лист, сверяет
запись с описанием `derive_spec.py` (куда в шаблоне ложится число каждого шага, коридор разумного, невязки правил, фазы
запуска), пишет числа в шаблон с печатью «было → стало», пересобирает книгу и печатает быстрые числа с приёмочными
проверками и проверками классов ошибок. Правила шагов — только в листе; при смене правила шага правятся лист и описание,
команда — нет.

Часть ключей книги — не суждения, а корни правил: их значение следует из суждения и из решения передачи ставки либо из
пути баланса клеток. Лист выводит их на ядре с включённым ограничением роста, в порядке зависимости; связанные шаги
повторяются, пока каждое число не перестанет меняться. Суждения, заданные числом, лист читает из книги и не трогает:
уровень маржи мира N (7,17 % опр. банка), передача ставки (−0,06 опр. банка), уровни строк к базе (середина двух
прочтений, решения ведущего № 12), премии роста. Числа вписаны в шаблон с пометкой «ВЫВЕДЕНО НА ЯДРЕ» и ЗАМОРОЖЕНЫ:
«цена правила», справочные варианты, оси полосы и обратный расчёт их не пересчитывают.

**Шаги книги 0.1** (фаза центра; запись — `out/derive_out.txt`):

| Шаг | Ключ | Правило |
|---|---|---|
| `bridge` | `nii.nim_lt_target_mgmt`, `nii.transmission.target` | суждения в опр. банка переводятся в базис движка точным мостом: маржа движка = маржа банка × R − ставка книги страховых мира × её доля; R 0,866, доля книги страховых 0,042, β книги 0,65 → ключ уровня 0,072965, цель передачи −0,079195 |
| `anchor` | `capital.n20.deductions_anchor`, `capital.n11.deductions_anchor`, плотность корпоративной книги | вычеты и плотность якоря числами — якорь воспроизводит Н1.0 (10,985 %) и Н1.2 (9,619 %) банка и RWA 4 365 млрд ₽ |
| `near_spreads` | ближние ключи спредов книг 2026–2027 | правило A-N1n от ставок книг якоря |
| `level` | — (проверка) | стационарная маржа мира N равна ключу; опр. банка — N 7,17 / H 7,21 / M 6,63 % |
| `splits` | `nii.sigma0_split`, `nii.phi_split` | σ0 — середина области 0…1 (свидетельств нет); φ — тип Б на границе: оценка «по истории» (0,42) вне области гейта стоимости средств, центр — ближайшая точка области 0,48 |
| `near` | `regimes.near_nim_shift` | 3К2026 — нау-каст 7,45 % опр. банка на ожидании слоя «свой взгляд»; сход к нулю к 2030К1 |
| `levels` | `opex.real_growth`, `fees.growth_vs_wages`, `other.insurance_growth_vs_wages` | корни под уровень строки к её базе в слое «рыночные ставки как есть»: расходы 2,344 % базы М13, комиссии 1,490 %, страхование 2,225 % базы книг; рост г/г 3–4-го кварталов 2026 года — ожидание слоя «свой взгляд» |
| `share_roots` | `opex.line_share_roots.*`, `volumes.liability_driver_roots.*` | κ франшизы строки и ρ номинальной части книги страховых — неподвижная точка на слое «рыночные ставки как есть» |

**Фаза концов** (на записанных числах центра): концы осей уровней строк — сами прочтения (года якоря целиком и окна R);
концы осей весов М13, баз комиссий и страхования, связи страхования, периметра окна R; ось интенсивности окон стоимости
риска; коридор `checks.wholesale_share` (0,08…0,25 по правилу листа); окно R для гейта `window_backtest` (стоимость риска
1,72…3,17 %, C/I 42,4…67,8 %, ЧПМ 4,08…7,55 %); цель гейта `cir_lt` — C/I слоя M при расходах на уровне окна (48,34 %,
допуск 0,9 п.п.); вариант «розничный хвост»; нижняя граница ROE модели для отбора окон строк-долей (Р11-8); κ и ρ на
концах связок — в допуске правила. Проверка, а не правило: «нужда баланса» — премия роста средств клиентов, при которой
кредиты модальной клетки равны её средствам клиентов к 2030 году (−5,57 п.п. в 2027 году); ось премии средств — диапазон
прочтений «факты» и «нужда».

Воспроизведение. Запуск с `--start out/derive_start.json` даёт `out/derive_out.json` и числа книги в точности. Запуск
без `--start` начинает с чисел самой книги и делает ещё один круг связанных шагов: числа остаются в пределах точности
записи (тест `tests/test_book_evidence.py`). Пересчитывать и перезаписывать числа книги по такому запуску нельзя — они
заморожены до новой версии.

## Предельная экономика роста (устав, раздел 4)

`marginal_loan.py` — проверка, ключей не пишет. На рядах ядра лист считает, что приносит на капитал дополнительный рубль
кредита в клетках «мягкая посадка × АЦН 1 % и консолидация страховщиков» трёх миров: процентный доход по ставкам книг
клетки, фондирование — ликвидными активами, пока они выше минимума, и оптовым фондированием, когда они на минимуме;
резервы — по стоимости риска года; расходы и комиссии — по связям книги; капитал — под требование норматива с глиссадой.
Норма — **единица сегмента корпоративного бизнеса**: кредит юрлиц со средствами юрлиц в отношении сегмента (1,36 на
рубль кредита на якоре) и гарантиями с комиссиями (решения ведущего № 4, Р4-4); кредит юрлиц на опте без франшизы и
розничная корзина — справочно. Запись — `out/marginal_loan_out.txt`: доходность единицы сегмента на капитал после налога
против стоимости капитала мира по годам; на ней стоит объяснение гейта знака объёмных эффектов `volume_sign`.

Если ядро не исполняет ветвь книги (схема называет её словом «не реализовано»), листы выходят с кодом 2.
