# nii — книги ЧПД, передача ставки, цель и ближний путь ЧПМ (A-N*, A-C4b, A-X8) — книга Совкомбанка

**Лист калибровки ЧПД Совкомбанка** — `svcb-850-handoff/stage1/calib-nii/` (источник истины — скрипты):

| Что | Где |
|---|---|
| Отчёт листа: двенадцать книг ЧПД (ρ, β, спреды), бэктест пути маржи 2023К1–2026К2, перенос окна L на состав якоря (ЧПМ мира N 7,17 %, ось 6,92–7,28 % — свободный подбор книг … середины наклонов), передача ключевой (−0,06; ось −0,15…+0,03), оценки сжатия истории φ, полы спредов | `REPORT-nii.md` |
| Бэктест книг и совместный подбор (наклоны доходности и стоимости к ключевой — `out/backtest.json`, поле `joint`) | `backtest.py`, `out/backtest.json` |
| Блок книги `nii` (предложение ключей) | `nii_block.py`, `nii_block.yaml` |
| Премии роста кредитов и средств клиентов к сектору (рост сектора окон — прочтение «факты» оси премии средств) | `volumes.py`, `volumes_block.yaml` |
| Панель ставок книг по кварталам | `build_panel.py`, `sheets/` |

Числа книги, которые выводятся на ядре (ближние ключи спредов, доли σ0 и φ, ближний сдвиг маржи, концы осей, нужда баланса и
концы оси премии средств), пишет команда перевывода — лист `../path/derive_on_engine.py` и его описание `../path/derive_spec.py`.

Лист книги-образца семейства (его входы и выходы) снят в медленном круге: их числа Совкомбанк не
описывали (решения ведущего № 11, Р11-7). В каталоге — листы приёмки бэктеста маржи на ядре и их входы.

```
python -B data/assumptions/evidence/nii/backtest_books.py [--book КНИГА] [--out ФАЙЛ]   # бэктест книг §5 1(б) на наклонах ядра
python -B data/assumptions/evidence/nii/backtest_path.py [--book КНИГА] [--out ФАЙЛ]    # бэктест пути маржи §5 1(б) (Р12-5)
```

Бэктест книг §5 1(б) на наклонах ЯДРА (`backtest_books.py`; решения ведущего № 11, Р11-1, проход ядра 9) — лист приёмки
команды перевывода: механика бэктеста листа этапа 1 (ставка книги a·EMA_ρ(опора) + c, ЧПМ банка из двенадцати книг), но
наклон a каждой книги — наклон модели между мирами (`model.nii.book_slopes`: доли сжатия книг `phi_share`, φ_A, φ_L, β),
ρ — книги, c — подбором с весами «центра» листа; гейт — 0,3 п.п. на каждом плече (L, W4, спуск, C). Входы — копии панели
ставок и совместного подбора листа этапа 1 и рядов опор окна (`inputs/stage1/calib/nii/backtest/`, опись `SOURCES.json`).
Числа плеч текущей книги — запись команды перевывода (описание приёмки) и лист решения круга.
