# Доказательные листы книги допущений Совкомбанка

Листы калибровки книги — в папке передачи (`svcb-850-handoff/stage1/calib-*`: капитал, отчёт о прибыли, ЧПД, режимы,
рынок); их числа ложатся в шаблон книги с источником в комментарии ключа. В дереве — листы, которые читает команда
перевывода книги и сборка шаблона: вывод чисел на ядре, листы приёмки, надстройка миров. Листы книги-образца семейства
(регулирование, капитал, отчёт о прибыли, ЧПД, режимы, рынок, управление, их общие помощники и выписка малых входов, лист
двух оснований маржи квартала после якоря) сняты в медленном круге: книга Совкомбанка их не читала, а их числа описывали
другой банк. Ответы брокерского API в листах не лежат — ни файлом, ни таблицей, ни выпиской
полей (`tests/test_book_evidence.py`).

| Область | Скрипты | Что даёт книге |
|---|---|---|
| `path/` | `derive_on_engine.py` (описание для команды перевывода — `derive_spec.py`), `acceptance.py`, `m13_cost_bases.py`, `marginal_loan.py` | вывод на ядре чисел, которые следуют из суждений и из пути баланса (доли σ0 и φ, ближний сдвиг, корни строк, концы осей, нужда баланса, центр премии средств); листы приёмки: мерки маржи в условиях своих окон и сверка порядка (`acceptance.py`), базы расходов М13 (`m13_cost_bases.py`), предельная экономика роста (`marginal_loan.py`, устав §4); входы — `inputs/`, записи — `out/` |
| `nii/` | `backtest_books.py`, `backtest_path.py` | приёмка бэктеста маржи §5 1(б): бэктест книг на наклонах ядра (Р11-1) и путь маржи в модели (Р12-5, определение «c подбором» — лист решения № 12, С-2); входы — копии панели ставок и совместного подбора листа `calib-nii` (`inputs/stage1/calib/nii/backtest/`, опись `inputs/SOURCES.json`) |
| `worlds_bank/` | `build_overlay.py` | надстройка миров `worlds_bank.json`: рост сектора по группам кредитов и средств клиентов — один у банков семейства (сверка с надстройкой семейства бит в бит) |
| `assemble/` | `assemble_template.py` (каркас `template_skeleton.yaml`, части `valuation_part.yaml`, `checks_part.yaml`) | запись того, из чего родился шаблон книги (фаза 3, 21.10.2026); после сборки шаблон правят руками и командой перевывода |

Порядок у новой версии книги: `python -B ops/tools/rederive.py [--dry-run]` из корня репозитория — лист вывода на ядре,
описание `path/derive_spec.py`, листы приёмки (`ACCEPTANCE`), проверки классов (`data/assumptions/class_checks.yaml`),
быстрые числа; надстройка миров — `python -B data/assumptions/evidence/worlds_bank/build_overlay.py --check`.
