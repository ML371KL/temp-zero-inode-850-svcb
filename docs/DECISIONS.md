# Решения: владельца и ведущего

Журнал решений, на которых стоят модель и конвейер панели «Совкомбанк 850». Числа
книги с опорами и осями — `data/assumptions/ASSUMPTIONS-BOOK.md`; методика —
`docs/MODEL.md`; контракт выпуска — `docs/PAYLOAD.md`. Решение меняется только новым
решением с датой (запись ниже, старая не стирается); книга — только новой версией.
Решения панелей семейства, на которых стоит общий код (образец логики и витрины —
панель Сбера, образец кода — дерево второй банковской панели семейства), — в их
журналах (`docs/DECISIONS.md` их репозиториев); здесь из них названы те, что действуют
как решения семейства.

Обозначения: [Ф] — факт с источником, [Р] — расчёт, [В] — суждение. Доли — как в
книге (0,001 = 0,1 п.п.). Базисы: МСФО группы ПАО «Совкомбанк»; РСБУ банка;
нормативы банка по формам ЦБ (Н1.0, Н1.2); упр. — метрики в определении банка; движок
— базис ядра после мостов. Прибыль движка — отчётная прибыль акционеров по МСФО
(купон бессрочных — через капитал). Дроблений и консолидаций акций после IPO не было.

## Часть 1. Решения владельца (21.10.2026)

1. **Задача** (21.10.2026). По логике, принципам и практикам модели Сбера построить
   модель справедливой стоимости акции ПАО «Совкомбанк» (тикер SVCB, Мосбиржа) и
   дашборд https://tzi-850-svcb.pages.dev — с учётом собственной экономики банка.
2. **Репозитории — публичные,** отдельные на банк: код —
   `ML371KL/temp-zero-inode-850-svcb` (`main`), выпуски —
   `ML371KL/temp-zero-inode-850-svcb-data` (ветка `release`, GitHub Pages).
3. **Новая папка.** Работа идёт в своей рабочей копии и своей папке передачи;
   репозитории и папки панелей Сбера, Т-Технологий и ВТБ не меняются — они на бою.
4. **Доступы и разрешения** — владелец дал все, что нужны для работы над панелью
   (сервер, токен брокерского API, репозитории, Cloudflare Pages). Значений здесь нет:
   их хранит справочник владельца вне репозитория.
5. **Порядок работы** — порядок семейства 850 (сначала экономика на быстром круге,
   остановки после быстрых чисел, приёмочные проверки чисел).
6. **Последний быстрый круг** (28.10.2026). Двенадцатый круг калибровки — последний:
   после него — медленный круг (код, тексты и проверки, числа книги не меняются) и
   выпуск; всё должно быть безупречно.

### Унаследованные решения семейства

Приняты владельцем для панели Сбера (30.09–06.10.2026) и действуют здесь без
изменений.

- **ERP — 5,57 %,** конвенция семейства 850; разрыв с рынком печатается строкой «что
  в цене», а не подгоняется.
- **Репозиторий на банк.** Общность держится правилами: ни одного литерала банка в
  `model/`, `indicators/`, `web/app.js`, `functions/` (имя, тикер, регномер, даты — из
  книги и `meta.company`) и журнал переноса исправлений `docs/PORTING.md`.
- **Сервер и секреты разрешены.** Сбор, приватный сырой архив с винтажами, журнал
  прогнозов, сборка и публикация — на общем сервере панелей владельца (systemd,
  пользователь `dash`); код и выпуски — публичные репозитории; CI — GitHub Actions;
  витрина — Cloudflare Pages; тревоги и сторож свежести — общие для панелей.
- **T-Invest подключается:** токен «только чтение»; условия API запрещают публичные
  сервисы на нём — витрина для личного пользования, в выпуск идут только агрегаты,
  которые печатает витрина; ответы API в репозиторий не переносятся ни выписками, ни
  именами полей.
- **Ручной слой — Claude по просьбе владельца;** всё, что можно, автоматизируется.
- **Защиту сайтов от ботов не обходим.** Сайт банка защищён от ботов — его не
  обходим; документы эмитента лежат на открытом сервере раскрытия.
- **Миры ставок** — байтовая копия записи семейства и её рецепт; одна конвенция
  вероятностей; кризис — режим доходности и кредитного цикла, а не четвёртый мир.
- **Метод:** остаточный доход — печать, дивидендная модель с капитальным ограничением
  — инвариант сборки; шаг — квартал, простые проценты по дням, сложный процент —
  только в дисконте; явный горизонт до 2036К4 и терминал.
- **Витрина** — дизайн-система семейства, шесть экранов, без дисклеймеров и без
  фирменного стиля эмитента. Центры допущений несмещённые, осторожность — в
  диапазонах; сложность — только там, где окупается.

## Часть 2. Устав калибровки, фаза 2 (21.10.2026)

Устав написан ведущим до первых чисел движка: правила центров заданы от фактов,
пробный счёт проверяет решение, а не выбирает его.

- **Окна фактов и их условия.** Уровень маржи — окно 1-го полугодия 2023 года (ключевая
  7,5 %, стационар книг после девяти месяцев неподвижной ставки) — ставится в мир
  «Нормализация ставок». Стоимость риска, расходы, комиссии, страхование и «прочее» —
  окно 2К2024–2К2026 (ключевая 14,25–21 %, средняя 17,9 %, нынешний периметр после
  присоединения Хоум Банка) — в мир «Рыночный как есть». Окно спуска 4К2025–2К2026 —
  не уровень, а проверка ближнего пути маржи. Годы 2024–2025 уровнем прибыльности не
  берутся: основная банковская прибыль в них отрицательна.
- **Передача ставки в маржу** — центр −0,06 (регрессия истории −0,15…+0,03; пары
  кварталов с одинаковой ставкой −0,05); бэктест пути маржи по фактической ключевой на
  обоих плечах ставки.
- **Нормативы:** слот ядра `n20_0` ← Н1.0 банка, второй слот ← Н1.2 банка (связывает
  вторым); требования — лестница надбавок системно значимых банков 10,0 / 10,75 / 12,0 %
  (Н1.0) к 2028 году. Нормативы группы не раскрываются с 2К2025.
- **Выгодные покупки — 0 в центре** (правило семейства: сделки входят фактами якоря
  после закрытия); «серийный покупатель» — справочно с ценой.
- **Выкуп акций страховой дочкой** — 3 млрд ₽ в квартал до 2028К4, делитель — путь
  акций своей клетки, цена — рыночная цена мира.
- **Выплата** — середина наблюдённого 10–30 % прибыли акционерам: политика 25–50 % при
  Н1.0 не ниже 11,5 % не соблюдалась.
- **Шаг печати — 0,1 ₽** (около 1 % цены); он же порог существенной находки и
  «устоялось».
- **Типы центров** (решения № 11, раздел А): А — статистика окна (среднее скользящих
  четырёх кварталов в условиях модели), Б — совместный подбор той же механикой, что
  ядро, В — середина диапазона прочтений, Г — одно чистое наблюдение, Д — свидетельств
  нет (середина области), Е — конвенция семейства. Тип каждого ключа — в
  `data/assumptions/class_checks.yaml`.

**Развилки владельца и умолчания** (действуют без ответа; цена — справочными
вариантами книги):

| № | Развилка | Умолчание |
|---|---|---|
| О1 | Маржа «горба» 2026 года — переход или новый уровень | переход: уровень окна 1П2023 в мире «Нормализация ставок», передача −0,06 |
| О2 | Выгодные покупки — часть бизнеса или разовое | 0 в центре, «серийный покупатель» — справочно |
| О3 | Выкуп акций дочкой | 3 млрд ₽ в квартал до 2028К4 |
| О4 | Порядок замыкания капитала | «сначала уступает дивиденд» (до жетона 0,35 ₽), затем рост; цена двух других порядков — таблицей «цена правила» |
| О5 | Периметр капитала на витрине | нормативы банка (Н1.0 и Н1.2) против лестницы надбавок системно значимых банков |
| О6 | Материалы звонков эмитента (гайденс 2026 года) | гайденс — `null` с причиной, пока чисел в первичке нет |
| О7 | Якорь выпуска | выпуск на 2К2026; перезаякоривание на 3К2026 после отчёта МСФО за 9 месяцев 2026 года |

## Часть 3. Решения ведущего № 1–12 (28.10.2026)

Двенадцать быстрых кругов калибровки: листы этапа 1 → книга → быстрые числа (сетка и
малая полоса) → две независимые проверки экономики → решения ведущего на класс
ошибки, а не на экземпляр. Ядро получило девять проходов ключей, каждый — с методикой,
независимой контрольной моделью и мутациями; без ключей ядро считает как образец
бит в бит.

| Решения | Что решено |
|---|---|
| № 1 (листы этапа 1) | уровень маржи мира N — 7,17 % на составе баланса якоря (перенос окна книгами бэктеста); финансовые расходы страхования — книгой-обязательством ЧПД; кризис со ставочной частью маржи (середина двух прочтений 2022 года); комиссии — с резервом по гарантиям |
| № 2 | правки по первым числам: неработающие деньги — за обязательствами, а не постоянны в рублях; строки уровней — к базе своей строки (А2); порядок «рост первым»; проход ядра 1 — выкуп по цене мира (М3), точность хранения прогонов (М4), множители стоимости риска книг (М7), веса книг в базе расходов (М13) |
| № 3 | правка на класс: драйвер каждой строки и связь во всех мирах, уровни на составе якоря, опт гасится и добирается; проход ядра 2 — жетон DPS, база связи по строке, опт, терминал от стационарных ставок, RWA гарантий, драйвер книги страховых, резерв по книгам |
| № 4 | неразличимые прочтения — осями с центром посередине; периметр окна — к якорю; предельная единица роста — сегмент корпоративного бизнеса с франшизой; проход ядра 3 |
| № 5 | база страхования — по месту выручки (как у комиссий); проход ядра 4 — сложение связок, драйвер RWA гарантий, корень множителем |
| № 6 | «прочее» — реальными рублями семейства, центр и ось в одной форме; среднее окна — среднее скользящих четырёх кварталов; проход ядра 5 — доля неработающих денег ключом |
| № 7 | только данные книги: наклон прохождения переоценки облигаций в «прочее», доля неконтролирующих на периметре окна, франшиза страхования одной формой |
| № 8 | сплошная ревизия класса «статистика окна не на той величине» по всей книге; проход ядра 6 — франшиза страхования формой строки |
| № 9 | книга страховых обязательств с корнем номинальной части; ось стоимости риска сквозь цикл — диапазон данных, розничный хвост — развилкой; проход ядра 7 |
| № 10 | правила на класс: одна премия средств клиентов на все миры, доля неконтролирующих — окнами в условиях модели, свидетельства режимов — на периметре якоря; проход ядра 8 — форма связи франшизы, гейт стоимости средств на ожидании мира |
| № 11 | одна таблица типов центров на всю книгу; проход ядра 9 — доли сжатия книг ЧПД между мирами (совместный подбор), средства клиентов без книги страховых, неконтролирующие в рублях (развилкой) |
| № 12 | строки уровней (расходы, комиссии, страхование) — середина двух годовых прочтений: год якоря целиком и окно 2К2024–2К2026; доля сжатия φ — ближайшая к оценке точка области гейта; передача −0,06 остаётся, бэктест пути маржи печатается с ценой развилки; вероятности режимов без лет покупок с нераскрытым эффектом |

**Лист решения № 12 (28.10.2026): число устоялось.** Обе финальные проверки экономики на
итоговых числах — «устоялось»: ошибок дороже шага печати нет ни поодиночке, ни в сумме;
приёмочные проверки пройдены, отклонения названы с ценой; обзор классов ошибок на
итоговой книге чист. Быстрые числа (600 прогонов, общие случайные числа): точка
15,4764 ₽, медиана 14,8150 ₽; полная полоса таблиц книги (2 000 прогонов) — медиана
14,75 ₽ (печать 14,8), точка 15,48 ₽ (раздел 0 текста книги).

**Ответы листа № 12, исполненные в медленном круге** (числа не меняют): довод о
передаче — регрессия и пары кварталов, а не стационарный наклон совместного подбора;
передача −0,06 — хорда миров N и M; бэктест пути маржи — «с подбором» уровня на
окне; конвенции семейства учитываются при отборе окон книги; цены связей устава —
числами итоговой книги.

**Долги, не делаемые до выпуска** (цена на этой книге — 0): связь роста для строк
страхования и комиссий (правка ядра с независимой проверкой), шаг перевывода, пишущий
центр премии средств клиентов сам, ключ схемы для будущих макронадбавок к весам
риска.
